# Fullscreen Avoider NG documentation

Fullscreen Avoider NG is a GNOME Shell extension. While the *primary
monitor* (the one GNOME shows the top panel on) displays a fullscreen
window, it moves the top panel, the hot corner and notification banners to
another monitor, and back when the fullscreen window ends.
